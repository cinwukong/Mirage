# What's new in Mirage

Mirage shows the notes for a new version once, after it updates. Each version is a "## <version>" heading followed by
"- " lines, newest first.

## 3.0.2
- Subtitles now follow my voice sentence by sentence and scroll, so long replies are never cut off.
- Updates show a progress bar, and this note tells you what changed.
- A new Diagnostics page under Settings: test your microphone, see your graphics card, memory and my brain's status, and copy a report (without what you've said) when you need help.

## 3.0.1
- Safer: opening apps never goes through the command line, and I ask before typing into a terminal.
- Updates come only from published releases, are checked before they're installed, and roll back by themselves if the new version doesn't start.
- Downloads of my voice, hearing and brain are checked, so a broken download is never installed.
- The Claude Code "Log in" button works again.
